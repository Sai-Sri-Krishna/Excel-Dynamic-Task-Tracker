
# 📋 Task Management Tracker Dashboard

An interactive task management dashboard built using **Microsoft Excel** to monitor task progress, team performance, task ownership, and overdue tasks.

## 📌 Project Overview

This project focuses on tracking tasks, monitoring progress, and analyzing workload distribution across teams and task owners using an interactive Excel dashboard.

## 📊 Dashboard Features

- **Completed Tasks:** Tracks the number of completed tasks.
- **In Progress Tasks:** Displays tasks currently in progress.
- **Not Started Tasks:** Shows tasks that have not yet started.
- **Total Tasks:** Displays the total number of tasks.
- **Overdue Tasks:** Identifies tasks that have passed their deadlines.
- **Tasks by Owner:** Visualizes task distribution among individual owners.
- **Tasks by Team:** Shows the number of tasks assigned to each team.
- **Task Details:** Displays task IDs, names, teams, owners, start dates, due dates, duration, status, overdue indicators, and comments.
